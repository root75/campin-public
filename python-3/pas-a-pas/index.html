    🐍 Texte, nombre et input()

    On écritPython y voit
    "3"un texte (str) : "3" + "4" colle → 34
    3un nombre entier (int) : 3 + 4 calcule → 7
    3.5un nombre à virgule (float), avec un POINT
    "ha" * 3le texte recopié → hahaha
    "Vies : " + 3refusé : TypeError. Écrire print("Vies :", vies)

    ⭐ input( ) rend TOUJOURS un texte. Pour un nombre : nombre = int(input("Un nombre ? ")).

    Un input( ) = une réponse à taper. Dans Thonny, la console attend : tape, puis Enter.

    Logigramme : Lire → int(input(…)) ; ← → = ; × → * ; Afficher → print( ).

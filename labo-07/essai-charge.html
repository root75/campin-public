Banc d’essai

Faire travailler le processeur, occuper la mémoire, figer un onglet — puis observer dans le Gestionnaire des tâches. Rien n’est envoyé ni enregistré.

Ce PC : …

1. Faire travailler le processeur

Un calcul sans fin sur chaque processeur logique choisi. Arrêt automatique après 3 minutes.

À l’arrêt.

2. Occuper la mémoire

Réserve de la mémoire vive et l’occupe réellement, par blocs de 256 Mo. « Libérer » la rend aussitôt.

Rien d’occupé.

3. Figer cet onglet

La page ne répond plus : les boutons et le défilement ne réagissent plus. Chrome peut afficher « Page ne répond pas ».

Pour arrêter un onglet figé, sans fermer Chrome ni les autres onglets :

  1. Chrome ▸ ⋮ en haut à droite ▸ Plus d’outils ▸ Gestionnaire de tâches (ou Maj + Échap).
  2. Clique sur la ligne « Onglet : Banc d’essai — Labo 07 ».
  3. Bouton Arrêter le processus.

Ou plus simple : le × de l’onglet. Dans la fenêtre « Page ne répond pas » : Quitter les pages.

Pour le professeur : relever les valeurs

Dans PowerShell (⊞ Démarrer ▸ tape PowerShell ▸ Entrée), ce script relève le processeur et la mémoire chaque seconde pendant une minute, puis copie le résultat dans le presse-papiers.

$log = 1..60 | % { $c=(Get-CimInstance Win32_PerfFormattedData_PerfOS_Processor -Filter "Name='_Total'").PercentProcessorTime; $o=Get-CimInstance Win32_OperatingSystem; $m=[math]::Round(100*(1-$o.FreePhysicalMemory/$o.TotalVisibleMemorySize)); "{0:HH:mm:ss}  CPU {1} %  MEM {2} %" -f (Get-Date),$c,$m; Start-Sleep 1 }; $log | Set-Clipboard; $log

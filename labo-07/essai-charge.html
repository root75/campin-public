Pour le professeur : relever les valeurs

Dans PowerShell (⊞ Démarrer ▸ tape PowerShell ▸ Enter), ce script relève le processeur et la mémoire chaque seconde pendant une minute, puis copie le résultat dans le presse-papiers.

$log = 1..60 | % { $c=(Get-CimInstance Win32_PerfFormattedData_PerfOS_Processor -Filter "Name='_Total'").PercentProcessorTime; $o=Get-CimInstance Win32_OperatingSystem; $m=[math]::Round(100*(1-$o.FreePhysicalMemory/$o.TotalVisibleMemorySize)); "{0:HH:mm:ss}  CPU {1} %  MEM {2} %" -f (Get-Date),$c,$m; Start-Sleep 1 }; $log | Set-Clipboard; $log

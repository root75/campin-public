Lire les erreurs, commenter je révise

Le résumé de Python 02. Rien n'est coté.

L'essentiel en 6 lignes

  1. Ça ne marche pas ? Je lis le message, je trouve la ligne fautive, puis je corrige. Jamais au hasard.
  2. SyntaxError : l'écriture est cassée, un caractère de trop ou de moins : print(1 + 2 +).
  3. NameError : un nom inconnu. Vies n'est pas vies. Un texte sans guillemets aussi : nom = "Léa", pas nom = Léa.
  4. Erreur de logique : pas de ligne rouge, mais un résultat faux. Je fais la trace et je compare avec ce que j'attendais.
  5. Un nombre à virgule s'écrit avec un POINT : 0.9. Et 20 * 0.9 donne 18.0.
  6. # commence un commentaire : Python l'ignore, il explique le programme. Devant une instruction, il la désactive. (AltGr + 3)

Ensuite : le quiz (5 questions), puis les cartes pour réviser.

Cartes mémoire

Lis la question, réponds dans ta tête, puis clique sur la carte pour la retourner.

Ça coince ?

Le programme ne marche pas ? Quatre gestes :

  1. J'exécute et je lis la dernière ligne du message : le nom de l'erreur.
  2. Je trouve la ligne fautive (son numéro est dans le message), puis je corrige.
  3. Pas de ligne rouge, mais un résultat faux ? Je fais la trace, ligne par ligne.
  4. Perdu ? Je reviens à la version qui marchait, et je change un caractère à la fois.

Le rat de ville je révise

Pour t'entraîner avant le formatif et le bilan. Rien n'est coté.

L'essentiel en 5 lignes

  1. D'abord je sélectionne ce que je veux changer, ensuite je clique sur le bouton.
  2. Aligner, c'est un bouton ≡ ▾, jamais des espaces.
  3. B = gras, I = italique, U = souligné.
  4. Une vraie liste se fait avec le bouton : puces quand l'ordre ne compte pas, numéros quand il compte.
  5. Mon document s'appelle AAAAMMJJ Le rat de ville – Prénom Nom.

Ensuite : le quiz (5 questions), puis les cartes pour réviser.

Cartes mémoire

Lis la question, réponds dans ta tête, puis clique sur la carte pour la retourner.

Ça coince ?

Retiens trois gestes, toujours dans cet ordre :

  1. Je sélectionne (le texte devient bleu).
  2. Je clique sur le bouton.
  3. Je regarde si ça a changé.

J'ai fini

Défi : mets les strophes 1 et 2 en Garamond 14 en une seule sélection.

Ton score reste sur cet ordinateur. Aucune donnée n'est envoyée.

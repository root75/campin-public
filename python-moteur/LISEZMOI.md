# Moteur Python des fiches pas à pas

[Pyodide](https://pyodide.org) 0.27.7 (Python 3.12.7, compilé en WebAssembly), licence MPL-2.0.
Seuls les cinq fichiers du cœur sont ici : pas de paquets, `print` et les variables suffisent.

Servi par GitHub Pages, sur le même domaine que les fiches : le filtre du réseau de l'école n'a
pas d'autre adresse à laisser passer. Environ 14 Mo au premier « Exécuter », puis en cache.

Mettre à jour : `npm pack pyodide@<version>`, recopier les mêmes cinq fichiers, changer le numéro
ici et dans `MOTEUR` des fiches si le dossier change.

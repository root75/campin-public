Texte, nombre et input() je révise

Le résumé de Python 03. Rien n'est coté.

L'essentiel en 6 lignes

  1. Entre guillemets, c'est un texte : "3". Sans guillemets, un nombre : 3 (entier) ou 3.5 (à virgule, avec un POINT).
  2. Avec deux nombres, + calcule : 3 + 4 → 7. Avec deux textes, il colle : "3" + "4" → 34. Et "ha" * 3 → hahaha.
  3. Un texte + un nombre : TypeError. Pour afficher les deux, une virgule : print("Vies :", vies).
  4. input("…") pose une question, attend la réponse, et rend toujours un texte. Dans Thonny, la console attend : je tape, puis Entrée.
  5. int( ) transforme le texte en nombre : nombre = int(input("Un nombre ? ")). Sans lui, "3" * 10 → 3333333333.
  6. Logigramme → Python : Lire → int(input(…)) ; ← → = ; × → * ; Afficher → print( ).

Ensuite : le quiz (6 questions), puis les cartes pour réviser.

Cartes mémoire

Lis la question, réponds dans ta tête, puis clique sur la carte pour la retourner.

Ça coince ?

Le programme ne marche pas ? Trois gestes :

  1. TypeError : je mélange texte et nombre. Une virgule dans print, ou int( ) sur le texte.
  2. ValueError : int( ) a reçu autre chose qu'un nombre entier (des lettres, une virgule).
  3. Thonny semble bloqué après F5 ? Le programme attend : je clique dans la console du bas, je tape, puis Entrée.
  4. EOFError (dans la fiche) : un input( ) de trop, il lit une réponse qui n'a pas été tapée.

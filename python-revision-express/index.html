Avant l'évaluation révision express

Python 01 et 02 en cinq questions. Rien n'est coté.

L'essentiel en 6 lignes

  1. Une variable est une boîte avec un nom : billes = 8 range 8 dans la boîte billes.
  2. billes = billes + 5 : Python calcule à droite du =, puis range le résultat dans la boîte.
  3. Pour savoir ce qu'un programme affiche, je fais la trace : la valeur de la variable après chaque ligne.
  4. Un calcul qui n'est pas rangé est perdu : billes + 5 tout seul ne change pas la boîte.
  5. print(billes) affiche le contenu de la boîte. print("billes") affiche le mot billes.
  6. NameError : un nom inconnu. Billes n'est pas billes. Je lis le message, je trouve la ligne, je corrige.

Ensuite : le quiz (5 questions), puis les cartes pour réviser.

Cartes mémoire

Lis la question, réponds dans ta tête, puis clique sur la carte pour la retourner.

Ça coince ?

Une question te bloque ? Quatre gestes :

  1. Je fais la trace : j'écris la valeur de la variable après chaque ligne.
  2. Une ligne de calcul sans = ? Son résultat est perdu, la variable ne change pas.
  3. Des guillemets dans print ? Python affiche le mot tel quel, pas le contenu de la boîte.
  4. Un message rouge ? Je lis sa dernière ligne et je compare les noms, lettre par lettre.

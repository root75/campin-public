Bien communiquer en ligne je révise

Pour t'entraîner après Messagerie 03. Rien n'est coté.

L'essentiel en 6 lignes

  1. Un professeur, l'école : un courriel (Outlook, Gmail). Des amis, vite : une messagerie instantanée (WhatsApp, Messenger).
  2. Un message non lu est en gras, avec une barre bleue. Clic DROIT (le bouton de droite de la souris) ▸ Marquer comme non lu.
  3. Un spam va dans Courrier indésirable. Un message qui veut mon mot de passe : clic DROIT ▸ Signaler un hameçonnage.
  4. Cc : tout le monde voit l'adresse. Cci : copie cachée, personne ne la voit.
  5. La nétiquette : je salue, je signe, pas de MAJUSCULES (c'est crier), les émoticônes pour les amis.
  6. Une pause : Ctrl + Alt + Delete ▸ Verrouiller. Fin de l'heure : touche Windows ▸ mon prénom ▸ Se déconnecter.

Ensuite : le quiz (6 questions, tirées parmi 18 : il change à chaque fois), puis les 18 cartes pour réviser.

Cartes mémoire

Lis la question, réponds dans ta tête, puis clique sur la carte pour la retourner.

Ça coince ?

Retiens quatre gestes :

  1. Avant d'écrire : courriel ou messagerie instantanée ?
  2. Un message douteux : je ne clique sur rien, clic DROIT ▸ Signaler.
  3. Beaucoup de destinataires : mon adresse dans À, les autres dans Cci.
  4. Je quitte mon poste : je verrouille (pause) ou je me déconnecte (fin de l'heure).

J'ai fini

Défi : explique à ton voisin la différence entre Cc et Cci, avec un exemple de ta vie.

Ton score reste sur cet ordinateur. Aucune donnée n'est envoyée.

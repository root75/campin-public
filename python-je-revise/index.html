Premiers pas en Python je révise

Pour te remettre en route après le congé. Rien n'est coté.

L'essentiel en 5 lignes

  1. print(...) affiche : un texte entre guillemets print("Bonjour"), ou ce qu'il y a dans une variable, sans guillemets print(vies).
  2. Une variable, c'est une boîte qui porte un nom. = range une valeur dedans : c'est la flèche ← du logigramme.
  3. vies = vies - 1 : à droite je calcule, à gauche je range. La boîte est toujours à gauche.
  4. Python lit chaque lettre : Vies n'est pas vies, Print n'est pas print.
  5. Avant d'exécuter, je prédis ce qui va s'afficher, ligne par ligne, comme une trace.

Ensuite : le quiz (5 questions), puis les cartes pour réviser.

Cartes mémoire

Lis la question, réponds dans ta tête, puis clique sur la carte pour la retourner.

Ça coince ?

Le programme ne marche pas ? Trois gestes :

  1. Je lis le message d'erreur jusqu'au bout.
  2. NameError : Python ne connaît pas ce nom. Je vérifie les majuscules, et que la variable est créée avant.
  3. SyntaxError : c'est l'écriture. Je vérifie les guillemets et les parenthèses.

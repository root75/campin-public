Activités Info · 2e · la messagerie

Mon premier message je révise

Pour t'entraîner après la leçon 1 de messagerie. Rien n'est coté.

L'essentiel en 5 lignes

  1. Un e-mail, c'est une lettre : À = l'adresse sur l'enveloppe, l'objet = de quoi ça parle.
  2. Un message bien écrit : Bonjour…, mon texte, une formule pour finir, ma signature (prénom, nom, classe).
  3. Boîte de réception = ce que je reçois. Éléments envoyés = ce que j'ai envoyé.
  4. Brouillons = ce que j'ai commencé sans l'envoyer.
  5. Un message envoyé ne se reprend pas : je relis avant Envoyer.

Ensuite : le quiz (5 questions), puis les cartes pour réviser.

Cartes mémoire

Lis la question, réponds dans ta tête, puis clique sur la carte pour la retourner.

Ça coince ?

Retiens quatre gestes, toujours dans cet ordre :

  1. Je remplis À, puis Ajouter un objet, puis le texte.
  2. Je relis les cinq points.
  3. Je clique sur Envoyer.
  4. Je vérifie dans Éléments envoyés.

J'ai fini

Défi : écris un second message à ton voisin, objet Question - prénom, avec les quatre parties d'un message bien écrit.

Ton score reste sur cet ordinateur. Aucune donnée n'est envoyée.
